## 1. Cómo publicar tu Portfolio GRATIS en GitHub Pages (3 minutos)

1. Crea un repositorio nuevo en GitHub llamado exactamente: **`Kill4Infinity.github.io`** (público).
2. Abre la terminal en esta carpeta (`C:\Users\Infinity\.gemini\antigravity\scratch\aitorjc-portfolio`) y ejecuta:

```bash
git init
git add .
git commit -m "Initial portfolio launch"
git branch -M main
git remote add origin https://github.com/Kill4Infinity/Kill4Infinity.github.io.git
git push -u origin main
```

3. En GitHub, entra a **Settings → Pages** → en *Branch*, asegúrate de que esté seleccionado `main` / `(root)`. En ~1 minuto tu web estará online en `https://kill4infinity.github.io`.

*(Después puedes poner `https://kill4infinity.github.io` tanto en tu perfil de **GitHub** como en el campo de enlace de **Fiverr**).*
